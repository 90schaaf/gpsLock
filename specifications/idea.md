# IDEA for gps based chaster extension

## Goal
A beta available extension for chaster to modify the lock behaviour based on the users gps location. It should work for iPhone as as well android phones.

## Methodology
1. use spec driven development to analyse first in question the indent, features and behaviour of the app. Give as well own ideas for the extension.
2. Do detailed analysis by refinmenent each feature request and write detailed specification upon the question & refinmenent.
3. implement in multiple iterations the extension and include tests.

Build up a technical readme how to setup and wire the extension with the chaster app.
Build up a small separate user guide how to use the extension and the features.

## Restrictions
1. app should run as a github page
2. documentation should be available as a github page
